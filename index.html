§ 01

Profil

Deux formations, une seule ambition : rendre l'IA utile là où elle est déployée.

Mon parcours est double : un BTS Développement d'applications informatiques qui m'a enseigné l'ingénierie logicielle depuis la ligne de code, puis un cycle ingénieur à l'EHEIM Oujda en option IA pour l'algorithmie, la statistique et le raisonnement des modèles.

J'aime les projets où l'IA n'est pas un pitch mais un composant qu'il faut faire tenir dans un produit : un chatbot RAG qui écoute vraiment le contexte métier, une app hospitalière qui doit être aussi fiable qu'utile, une API qui répond en 200 ms sous charge. Je travaille avec Python pour la partie modélisation et Laravel 11 / React 19 / Flutter pour livrer.

Je cherche pour mon PFE une équipe qui prend au sérieux les deux moitiés du métier — la recherche et l'exécution. Ma boîte mail est ouverte.
